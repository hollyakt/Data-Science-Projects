# Healthcare Analytics Portfolio

This portfolio bundles five recruiter-facing analytics projects built from public health and healthcare datasets. The same work is also published as a GitHub Pages portfolio at https://hollyakt.github.io/portfolio/.

## Projects

1. [Tableau heart disease dashboard](./project-01-tableau-heart-disease/README.md)
2. [BRFSS health disparities in R](./project-02-brfss-health-disparities-r/README.md)
3. [Debt collection complaints in Excel](./project-03-excel-debt-complaints/README.md)
4. [Pennsylvania hospital performance in Power BI](./project-04-powerbi-pa-hospitals/README.md)
5. [REDCap liver study abstraction](./project-05-redcap-liver-study/README.md)

These projects were built to demonstrate end-to-end healthcare analysis skills across dashboarding, survey methods, Excel business analysis, Power BI, and REDCap abstraction workflows.

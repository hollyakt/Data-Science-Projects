# Question

Which states have the highest burden of heart disease deaths, and how has that changed from 2015 to 2022?

# Data

A cleaned state-level heart disease deaths dataset assembled for a Tableau Public dashboard. The file includes annual deaths by state and demographic group for 2015-2022.

# Finding

Heart disease mortality remains highest in the Southeast and Appalachian states, with the most elevated burden in Mississippi, Alabama, and West Virginia.

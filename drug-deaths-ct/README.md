# Drug Overdose Deaths in Connecticut (2012–2023)

Exploratory analysis of accidental drug-related deaths in Connecticut, 2012–2023.

Course: PUBH 1242, Georgetown University.

## View the notebook

- [Open on nbviewer](https://nbviewer.org/github/hollyakt/Data-Science-Projects/blob/main/drug-deaths-ct/analysis.ipynb)
- [Open in Colab](https://colab.research.google.com/github/hollyakt/Data-Science-Projects/blob/main/drug-deaths-ct/analysis.ipynb)

Cell outputs are stripped to keep the repo lightweight — run the notebook (locally or in Colab) to regenerate the figures.

## Data

[Accidental Drug Related Deaths 2012–2023](https://data.ct.gov/Health-and-Human-Services/Accidental-Drug-Related-Deaths-2012-2023/rybz-nyjw) — Connecticut Open Data Portal. Download the CSV and place it at `data/deaths.csv` relative to the notebook (see the loading cell at the top of `analysis.ipynb`).
